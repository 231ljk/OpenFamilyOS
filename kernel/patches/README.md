# kernel/patches/ — 基线补丁组织

本目录存放针对 Linux 内核基线的少量补丁。开轮版的原则是**能不动基线就不动**：
所有核心能力优先用可加载模块实现，只有确实需要侵入内核路径的优化才落在这里。

## 规则

1. 每个补丁独立可 `git am` / cherry-pick，失败可单独跳过（能力降级，不报错）。
2. 文件名：`NNNN-简述.patch`（如 `0001-fork-add-exec-notify-timestamp.patch`）。
3. 补丁头必须写明：动机、影响范围、是否有 upstream 意向（有则附 lore 链接）。
4. 禁止：改默认行为、改对外 ABI、塞入与开轮版无关的功能。

## 应用与回退

```bash
# 在干净的内核源码树中依次应用
git am patches/*.patch

# 回退全部
git am --abort            # 应用中出错时
git reset --hard          # 已应用后回退
```
