# fosfs 存储格式规范（v0.1 · 开轮版参考设计）

> 状态：草案（v0.x 允许不兼容修订；正式 1.0 冻结后遵循「只增不改」）。
> 适用范围：FamilyOS 系统内部存储。对外互通仍走 ext4 / exFAT / NTFS，
> fosfs 只在系统盘与私有缓存内部使用 —— 「通用标准 + 自研模块」的分工。

## 1. 设计目标

| 能力 | 手段 |
| --- | --- |
| 加密 | 块级可选加密（信封加密：主密钥派生自设备 TPM/口令；参考实现留接口） |
| 压缩 | 块级 zlib（可换算法，记录在块头 `comp` 字段） |
| 快照 | 命名快照 = 不可变根清单块，写时复制天然成立 |
| 元数据扩展 | TLV 扩展区：新字段追加，旧解析器忽略未知类型 |
| 校验 | 每块 SHA-256；全盘扫描可检出静默损坏 |

非目标（开轮版刻意不做，留给社区/闭源分支）：日志事务、写时分配树、
原生 POSIX 权限 —— 参考实现是**格式契约 + 可运行演示**，不是生产文件系统。

## 2. 卷布局

```
偏移 0        512B          之后
┌───────────┬──────────────────────────────┐
│ superblock│  chunk 流（顺序追加）          │
└───────────┴──────────────────────────────┘
```

### 2.1 superblock（512 字节，小端）

| 偏移 | 大小 | 字段 | 说明 |
| --- | --- | --- | --- |
| 0 | 8 | magic | `FOSFS001` |
| 8 | 4 | version | 1 |
| 12 | 4 | flags | bit0 全盘加密（块密钥派生方式不同） |
| 16 | 8 | created_ms | 创建时间（Unix 毫秒） |
| 24 | 16 | uuid | 卷唯一标识 |
| 40 | 4 | hash_algo | 0=sha256（v0.1 唯一值） |
| 44 | 4 | comp_algo | 0=zlib（v0.1 唯一值） |
| 48 | 8 | chunk_count | 已写块数（尽力维护，verify 不信任它） |
| 56 | 8 | next_off | 追加写偏移 |
| 64 | … | reserved | 0 填充；TLV 扩展从这里开始追加 |

### 2.2 chunk（块流中的最小单位）

```
┌────────────────────────────┬─────────────┐
│ chunk header (48B)         │ payload     │
└────────────────────────────┴─────────────┘
```

| 偏移 | 大小 | 字段 | 说明 |
| --- | --- | --- | --- |
| 0 | 8 | magic | `FOSCHK01` |
| 8 | 1 | type | 1=数据块 2=清单块 3=快照根 4=删除墓碑 |
| 9 | 1 | comp | 0=raw 1=zlib（数据块）；清单/根固定 1 |
| 10 | 1 | enc | 0=明文 1=加密（密钥槽 id） |
| 11 | 1 | reserved | 0 |
| 12 | 2 | name_len | 名称 UTF-8 长度 |
| 14 | 4 | payload_len | |
| 18 | 2 | ext_len | TLV 扩展区长度（0 起） |
| 20 | 4 | seq | 序号（重放/对账用） |
| 24 | 8 | raw_len | 解压后长度 |
| 32 | 32 | sha256 | **解压后** payload 的哈希 = 内容地址 |
| 64… | | name | 数据块=文件路径；根块=快照名；墓碑=被删对象名 |
| | | ext | TLV：`[2B tag][2B len][value]`，未知 tag 跳过 |
| | | payload | 压缩（comp）后的字节；enc=1 时整体再加密 |

**内容寻址**：同一 `sha256` 的数据块只需存一份；重复写入只追加清单变更。

### 2.3 清单块（type=2，payload=JSON）

```json
{"files": {"a.txt": "sha256hex…", "b.bin": "…"}, "seq": 17}
```

每次 `put` 追加一份新清单（旧清单不可变）；读取时取**最后一个**清单块。

### 2.4 快照根块（type=3，name=快照名）

payload 与清单块同构。`snapshot("before-upgrade")` = 把当时清单复制为
根块；`rollback("before-upgrade")` = 把根块内容改写为新清单块 ——
写时复制由「不可变块 + 可替换清单」天然保证。

### 2.5 墓碑（type=4）

删除动作只追加墓碑块（payload 空），清单中移除对应项。
压缩/整理（`compact`）时物理回收无引用的旧块。

## 3. 加密（接口占位，参考实现不启用）

`enc=1` 的块：`payload = AES-256-GCM(key_slot, nonce=sha256[0:12], aad=header)`。
密钥槽派生规则在 v0.1 冻结格式但**不提供实现**（TPM/口令策略属于闭源
分支与社区各自演进的部分，格式层只保证字节布局可承载）。

## 4. 与缓存层的关系

开发文档中「缓存层：私有格式」复用 fosfs 块流：缓存条目 = 短 TTL 数据块
+ 扩展区 TLV `tag=0x0001 {ttl_ms}`。缓存目录是独立卷（`cache.fosvol`），
可随时删除重建 —— 快照语义不适用。
