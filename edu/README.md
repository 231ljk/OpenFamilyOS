# edu — 教育系统（独立子系统）

FamilyOS 中的独立子系统：**与日常系统并行存在，数据完全隔离**。
主要面向平板、电脑、电视设备（手表/手机作为遥控器与提醒端）。

## 子系统边界

| 维度 | 隔离策略 |
| --- | --- |
| 数据 | 独立 fosfs 卷（`edu.fosvol`），家长面板可一键清空，不碰日常数据 |
| 网络 | 课程资源缓存优先本地，联网白名单制（教育站点清单） |
| 账号 | 教育账号与家庭账号关联但权限独立（受限档走 `health` 服务） |
| 界面 | 进入教育系统 = 桌面形态切换（参考 `devices/` 电视/平板布局） |

## 课程目录结构

```
edu/
├── catalog.json               # 课程总目录（四类课程 + 元数据）
├── courses/
│   ├── school/                # 学校课程：常规学科内容
│   ├── extracurricular/       # 校外课程：培训班、兴趣班
│   ├── featured/              # 特色课程：AI 训练、AI 零基础搭建、3D 建模
│   └── vendor/                # 厂商课程：各大厂商开发者课程
├── programming/               # 编程进阶路径
│   ├── path.json              # 基础操作→图形化→Python→C++→硬件原理→系统开发
│   ├── 01-basics/             # 基础操作
│   ├── 02-blockly/            # 图形化编程
│   ├── 03-python/             # Python 入门
│   ├── 04-cpp/                # C++ 进阶
│   ├── 05-hardware/           # 硬件原理
│   └── 06-osdev/              # 系统开发（用开轮版本身教学！）
└── adventure3d/               # 3D 场景闯关实践模块
    ├── README.md              # 引擎接口约定与场景格式
    └── scenes/                # 场景定义（JSON）
```

## 四类课程（对齐开发文档第五章）

| 课程类别 | 内容说明 | 目录样例 |
| --- | --- | --- |
| 学校课程 | 覆盖常规学校教授的学科内容 | `courses/school/math-grade4-01/` |
| 校外课程 | 培训班、兴趣班等拓展内容 | `courses/extracurricular/robotics-stem/` |
| 特色课程 | AI 训练、AI 零基础搭建、3D 建模等前沿方向 | `courses/featured/ai-zero-to-model/` |
| 厂商课程 | 各大厂商提供的开发者课程 | `courses/vendor/example-dev/` |

每门课一个目录，包含 `course.json`（元数据）+ `lessons/*.md`（讲义）
+ `assets/`（可下载资源）。**样例课已就位，欢迎 PR 扩充目录。**

## 编程进阶路径

```
基础操作 → 图形化编程 → Python → C++ → 硬件原理 → 系统开发
   01         02         03      04        05          06
```

终章 06-osdev 的教材就是本仓库：
学生会拿到开轮版源码，读懂 `services/common`（300 行 IPC 骨架），
然后自己写一个系统服务 —— 从使用者变成创造者，正是「开轮」的闭环。

## 3D 场景闯关

`adventure3d/`：知识点包装成 3D 关卡（物理/数学/编程思维关卡），
引擎接口与场景 JSON 约定见其 README。参考实现提供引擎抽象层，
渲染后端（OpenGL ES/WebGL/自研）留给社区 —— 又一次「接口 + 可替换」。

## 家长端联动

- 学习时长经 `services/health` 记账（教育应用同样受禁用名单约束，
  但家长通常「只看不禁」—— 面板默认视图）；
- 进度报告每周生成，走超级环推给家长手机/手表。
