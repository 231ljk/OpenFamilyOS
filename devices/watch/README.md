# devices/watch — 手表（arm64，裁剪基线）

## 定位

概念验证阶段。手表在开轮版生态里的角色不是「独立跑应用」，
而是超级环的**提醒端与采集端**：

- 接收健康使用、课程提醒、场景联动通知（超级环 `ctrl`/通知通道）；
- 运动/心率数据本地记录（fosfs 卷），经互传同步到手机/电脑；
- 表盘即 `res/` 资源 + 极简渲染层（不做 3D）。

## 配方

- 内核：Linux 6.6 LTS 裁剪（`allnoconfig` + 触屏/传感器/低功耗必要项）
- rootfs：仅 `services/common` 库 + 微型代理守护进程（后续拆分）
- 省电：深度休眠优先，语音/蓝牙保持监听
