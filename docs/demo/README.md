# FamilyOS 3D 展示

浏览器直接打开即可（本地打开或经 GitHub Pages 在线访问）：

| 文件 | 内容 | 操作 |
| --- | --- | --- |
| `familyos-phone-3d.html` | 3D 模型手机 —— 立体机身 + 可操作屏幕（锁屏 / 桌面 / 8 个应用 / 系统信息） | 点击屏幕解锁、打开应用，拖拽旋转 |
| `familyos-3d.html` | 3D 系统运行界面 —— FOS KERNEL 核心 + 7 个服务节点 + 启动日志 | 拖拽旋转，点击空白切换自动旋转 |

> 渲染依赖 jsDelivr CDN（Three.js），需联网打开。
